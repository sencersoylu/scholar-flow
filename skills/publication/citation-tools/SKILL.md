# Citation Tools

Utility scripts for managing academic references without requiring a full reference manager.

## When to Use
- When you need to quickly convert a DOI to BibTeX
- When extracting metadata from PubMed IDs
- When validating a bibliography for completeness and consistency
- When converting between citation formats

## Scripts
- `doi_to_bibtex.py` — Convert DOI to BibTeX entry via CrossRef API
- `pubmed_metadata.py` — Extract citation metadata from PubMed IDs via NCBI E-utilities
- `citation_validator.py` — Validate a .bib file for missing fields, duplicate keys, and format issues

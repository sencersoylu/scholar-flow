# Getting Started with Scholar Flow

## Prerequisites

- [Claude Code](https://claude.ai/code) CLI installed and configured
- Python 3.11 or higher
- Git

## Installation

```bash
git clone https://github.com/sencersoylu/scholar-flow.git
cd scholar-flow
uv sync
```

## Configuration

Copy the environment template and add your API keys:

```bash
cp .env.example .env
```

Edit `.env` with your keys. All keys are optional but enhance search capabilities.
